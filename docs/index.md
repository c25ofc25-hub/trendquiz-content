# 트렌드퀴즈 고객 지원

하루 5문제로 요즘 트렌드를 따라잡는 iOS 앱, 트렌드퀴즈의 지원 페이지예요.

## 문의

앱 사용 중 궁금한 점이나 문제, 문제 내용의 오류 제보는 이메일로 보내 주세요.

## 자주 묻는 질문

**하루에 몇 문제를 풀 수 있나요?**
매일 5문제(새 문제 3개 + 복습 2개)가 나와요. 결과 화면에서 하루 한 번 5문제를 더 풀 수 있어요.

**새 문제는 언제 올라오나요?**
매주 월요일에 새 문제가 올라와요. 앱을 업데이트하지 않아도 돼요.

**기록을 초기화하고 싶어요.**
진행 기록은 기기에만 저장돼요. 앱을 지웠다가 다시 설치하면 처음부터 시작해요.

**광고 추적을 끄고 싶어요.**
iPhone 설정 > 개인정보 보호 및 보안 > 추적에서 끌 수 있어요. 꺼도 모든 기능을 똑같이 쓸 수 있어요.
