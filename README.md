# trendquiz-content

트렌드퀴즈 앱이 받아오는 문제와 "이번 주 화제" 데이터. 앱은 켤 때마다 아래 파일을 받아 쓴다.

```
https://raw.githubusercontent.com/c25ofc25-hub/trendquiz-content/main/content.json
```

- `main` 브랜치에 합쳐진 내용이 곧 앱에 나간다. 앱 업데이트는 필요 없다.
- 받기에 실패하거나 문제가 5개 미만이면 앱은 앱 안에 들어 있는 문제를 쓴다.
- 형식이 틀린 문제는 앱이 그 문제만 빼고 쓴다. 합치기 전에 꼭 `node validate.mjs`를 돌린다.

## 매주 흐름

1. 매주 월요일 예약 작업이 새 문제 초안과 화제 카드 초안을 만들어 PR로 올린다.
2. 사람이 PR을 검수하고 고칠 것은 고친 뒤 합친다. 합치지 않으면 앱에는 아무것도 나가지 않는다.

## 검수 체크리스트

- [ ] 뜻과 유래가 `sources`에 적힌 출처와 맞는다
- [ ] 정답이 하나뿐이고, 오답 보기가 그럴듯하지만 분명히 틀리다
- [ ] 다른 문제의 정답 말이 이 문제의 보기에 들어 있지 않다 (같은 날 나오면 힌트가 된다. 앱이 피하긴 하지만 적을수록 좋다)
- [ ] `status`(rising 뜨는 중 / hot 유행 중 / old 철 지남)가 지금 상황에 맞다
- [ ] 화제 카드가 아래 "다루지 않는 것"에 걸리지 않는다
- [ ] `node validate.mjs`가 통과한다

## 문제 형식

```json
{
  "id": "w100",
  "type": "meaning",
  "category": "word",
  "term": "말",
  "prompt": "이 말, 무슨 뜻일까요?",
  "context": "예시 대화 (없어도 됨)",
  "options": ["보기 1", "보기 2", "보기 3", "보기 4"],
  "answer": 0,
  "explain": { "meaning": "뜻", "origin": "유래", "example": "예문" },
  "status": "rising",
  "addedAt": "2026-11-30",
  "sources": ["https://출처 주소"]
}
```

- `id`: 말(신조어)은 `w`, 밈·유행은 `m` 뒤에 세 자리 이상 번호. 이미 쓴 번호 다음부터.
- `type`: `meaning` 뜻 맞히기, `blank` 대화 빈칸, `whatis` 이게 뭐게(설명 보고 이름 맞히기), `alive` 살았나 죽었나(보기 2개: 지금 쓰는 말 / 철 지난 말)
- `category`: `word` 또는 `meme`
- `answer`: 정답 보기의 위치. 첫 번째가 0. 정답 위치는 문제마다 섞는다.
- `addedAt`: 추가한 날짜. 최근 7일 안이면 앱 홈의 "이번 주 새로 뜬 말" 개수에 들어간다.
- `sources`: 뜻이나 유래를 확인한 페이지 주소. 2026-11-23 이후 추가하는 문제는 필수.
- 같은 말을 다른 유형으로 내는 건 괜찮다. 같은 유형으로 두 번은 안 된다.

## 이번 주 화제 형식

```json
"issueWeek": {
  "label": "11월 5주차",
  "issues": [
    {
      "id": "i2026w48a",
      "title": "화제 제목",
      "lines": ["무슨 일이 있었는지", "왜 화제가 됐는지", "지금 상황"],
      "sourceName": "매체 이름",
      "sourceUrl": "https://..."
    }
  ]
}
```

`issues`가 비어 있으면 앱 홈에 화제 카드가 보이지 않는다. 매주 새 주차로 통째로 바꾼다.

## 지키는 것

- 사건·인물은 퀴즈로 내지 않고 화제 카드(3줄 요약)로만 다룬다.
- 화제 카드에서 다루지 않는 것: 사망이나 신변 문제, 수사·재판 중인 사안, 일반인 신상, 확인되지 않은 의혹.
- 지어낸 숫자나 통계를 넣지 않는다. 확인할 수 없는 내용은 쓰지 않는다.
- 문구에 대상을 드러내는 말("후배", "아이" 등)을 쓰지 않는다.
- 혐오, 비하, 선정적인 말은 유행하더라도 내지 않는다.
